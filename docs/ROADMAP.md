# Roadmap

## M0：工程与协作基线

- [x] 产品、规则和架构文档
- [x] Agent 协作协议
- [x] Issue 与 Pull Request 模板
- [x] 初始 CI 仓库契约检查
- [ ] TypeScript/Vite/Vitest 脚手架
- [ ] `main` 分支保护与必要检查

退出条件：第一个功能 Issue 可以由执行模型在不猜测架构的前提下开始开发。

## M1：确定性规则引擎

- 核心类型与命令分发
- 六角棋盘拓扑与地图生成
- 玩家、银行和库存不变量
- 初始放置状态机
- 掷骰与资源生产
- 道路、定居点和城市建造
- 强盗与弃牌
- 银行、港口和玩家交易
- 发展牌
- 最长道路与最大骑士力
- 胜利与终局

退出条件：固定 seed 的完整对局可由命令序列驱动并稳定回放。

## M2：无界面模拟器

- CLI 操作与脚本对局
- 状态保存、恢复和事件回放
- 非法命令与崩溃诊断
- 规则场景测试集

退出条件：可在 CI 中运行完整对局模拟。

## M3：本地浏览器界面

- 原创棋盘视觉系统
- 本地轮流操作
- 合法操作提示
- 隐藏信息交接界面
- 响应式布局与可访问性

退出条件：3–4 人能在一台设备上完成对局。

## M4：后续候选

- AI 玩家
- 联网多人
- 观战与对局分析

这些内容不属于首版承诺，必须重新规划后才能启动。

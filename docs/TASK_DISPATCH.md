# 协作入口（兼容跳转）

本文件不再维护角色入口或动态状态。

> **唯一协作入口：`docs/CHECKLIST.md`**

无论高阶规划/审查模型还是低阶执行模型，都只需收到：

> **根据 `docs/CHECKLIST.md` 执行。**

模型会在清单中自行：

1. 核对 GitHub 当前事实；
2. 识别自己的角色；
3. 找到最靠前且前置条件满足的工作项；
4. 自动确定对应 Issue、PR、分支与需要读取的规则文档；
5. 执行并在角色边界或外部门禁处停止。

旧提示词如果指向本文件，应立即转到 `docs/CHECKLIST.md`，不要继续从本文件寻找任务状态。

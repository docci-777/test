# Product Scope

## 产品目标

构建一款可在浏览器本地运行的原创六角格资源交易桌游，实现完整、可测试、可回放的标准基础玩法，并以此验证多模型软件开发协作流程。

## 目标用户

- 希望本地进行 3–4 人轮流对局的玩家
- 希望学习桌游规则引擎、状态机与测试方法的开发者

## M1 可交付结果

无界面的规则引擎可以使用固定 seed 完成一局游戏，拒绝非法命令，输出确定性事件日志，并通过核心规则测试。

## 首版包含

- 3–4 名玩家
- 标准随机地图生成和固定 seed 地图复现
- 初始放置、掷骰、资源生产、交易、建造、强盗、发展牌和胜利判定
- 最长道路与最大骑士力
- 状态序列化、恢复和事件回放
- 本地浏览器轮流操作

## 首版不包含

- 任何扩展包规则
- 2 人或 5–6 人变体
- AI 玩家
- 联网、房间、账号和持久化服务
- 付费、排行榜或社交功能
- 官方名称、美术、规则书文字或音频

## 成功指标

- 同一初始状态与命令序列始终产生相同结果
- 规则引擎分支覆盖率目标不低于 90%
- 所有已登记的规则边界场景具有回归测试
- UI 中不存在独立于引擎的玩法合法性判断
- 从空环境按 README 可重复安装、测试和构建

## 决策权限

- 产品范围、规则口径和最终合并：仓库所有者
- 架构与任务拆分建议：高阶模型
- Issue 范围内实现：执行模型
- 模糊或冲突事项：回到仓库所有者，不由执行模型猜测

# 实施附件：玩法契约 v1

日期：2026-09-07；Owner：Planner；T01 提交审查版本，独立审查及合并前不得据此开工。适用 T03/T04/T06/T07。本文完整定义首期规则；原稿保留作历史来源。修改须由 Planner 升版并同步任务。

## 地图与初始状态（G01）

固定数据见同目录 map-v1.json，225 格按 rows[y][x] 读取；左上 (0,0)，x 向右、y 向下，均为 0～14 整数。P/F/M 分别为平地/森林/山地。设施底层均为平地。基地也是设施，规则见下。
玩家固定 A/B/C；基地和全部初始单位坐标、种类在 JSON 中。基地 HP10，资源4，步兵 HP4/移动2/伤害2/价格2，骑兵 HP3/移动3/伤害2/价格3，弓兵 HP2/移动2/伤害2/价格2。单位初始标志均 false、移动格数0；非当前玩家不能行动。
三个据点初始中立，控制人 null，争夺 false；无随机生成、迷雾、地图外格、斜向移动。地图中心为 (7,7)。基地初始布局按静态地图验证通路，动态单位可以暂时封路。
地图通过几何/可达性验证不等于平衡性通过；各基地至三个据点的加权距离写在 MAP-VALIDATION.md，差异由 T07 实玩评估，不能声称三方完全对称或已达到20～40分钟。

## 回合、资源和行动（G02/G04）

轮号1～25；第 r 轮原始顺序为 [A,B,C] 循环左移 (r-1)%3，过滤已淘汰玩家。一轮结束才重建顺序；淘汰不改变其余玩家本轮先后。每位存活玩家每轮恰有一个玩家回合，轮转可能让同一玩家跨轮连续行动。
开局生成资源4后，立即进入 A 的第1轮回合，结算 +2 基地收入，因此首次可操作快照为 A6/B4/C4；B、C 各自首次回合才加2。每次回合开始一次性收入 2 + 有效控制据点数，然后重置本方单位行动标志及移动格数，进入 RECRUIT 阶段。收入不因刷新、失败命令、暂停恢复而再次结算。
RECRUIT 可招募一次、跳过招募，或直接结束回合。成功招募/跳过后进入 ACTION，不允许回到 RECRUIT。移动/攻击/占领在 RECRUIT 返回 WRONG_PHASE，界面提供明确跳过按钮。招募失败不扣资源、不结束阶段；ACTION 不能招募。
招募需存活单位数<10、资源足够；命令指定本方基地四邻的空平地/森林/山地（骑兵禁山），不可在基地本格、任何其他基地格、越界或单位占格生成。四邻无合法空格返回 NO_SPAWN_CELL；有空格但指定非法格返回 INVALID_SPAWN。新兵本回合 moved=true、acted=true、movedSteps=0，下次本方回合才可行动。每次成功招募扣一次对应费用。
ACTION 中每单位最多移动一次、攻击或占领一次；攻击/占领后禁止移动。移动后可攻击或占领；不动可直接攻击或占领。结束回合无需用完所有单位行动。
MOVE 提交不含起点的完整路径，长度至少1；每步四邻、无重复坐标（含起点）、不经过/落在任何单位或未毁基地格。进入平地成本1、森林/山地2，起点不收费，累计不超过移动力，骑兵路径不得含山地。按提交路径验证，不由服务端自动改路线。成功后 moved=true、movedSteps=路径长度；失败完全不改状态。

## 基地、伤害、反击（G03/G07）

未毁基地格不可进入、穿越、驻兵或招募；基地摧毁后底层平地可进入。守军只在相邻格，不存在同格守军优先级。ATTACK 明确选择敌方 unitId 或 baseOwner，距离按攻击者与目标坐标计算。
步兵/骑兵只攻击四邻敌方单位或基地。骑兵本回合已成功移动至少2格则攻击伤害3，否则2；格数不同于成本，进入一格森林花2点仍不冲锋。弓兵目标必须同一行或列，曼哈顿距离1～2，攻击者在山地时1～3；距离1基础伤害1，距离2或3为2。射线不检查阻挡，允许跨过单位、地形、基地；斜线即使曼哈顿距离2也不合法。
目标单位位于森林/山地减伤1，最终 max(1,基础伤害-减伤)。基地伤害同攻击基础值，无地形减伤，无自动防御、无反击。攻击任何目标均消耗 acted；不能攻击本方目标或已移除对象。
近战攻击后目标单位若存活，无论其兵种（包括弓兵）均立即反击1，且不消耗目标单位行动。反击受攻击者所在地形减伤，最低1，因此本版仍为1。弓兵主动攻击从不触发反击，包括距离1。目标已死不反击；反击不触发反反击、不带冲锋。HP 截断至0并立即删除死亡单位。
实例：骑兵走两格平地攻击森林中HP4步兵，伤害2，步兵剩2并反击1；骑兵只走一格森林攻击平地步兵伤害2。弓兵在山地攻击同列距离3平地单位伤害2；距离3斜向拒绝；相邻森林目标仍受1伤害。

## 据点与连续控制（G05/G08）

每据点保存 owner:null|PlayerId 和 contested:boolean。有效控制=owner非空且 contested=false。进入敌方控制的据点（任意兵种）立即 contested=true，保留历史owner；离开/死亡也不会自动解除争夺。进入中立据点不自动控制，仍 owner=null、contested=false。本方进入已争夺据点不自动恢复。
CAPTURE 只允许当前玩家尚未 acted 的步兵站在据点格执行，消耗 acted，设置 owner=当前玩家、contested=false。对本方已有效控制的据点重复占领返回 ALREADY_CONTROLLED，不耗行动。不能远程占领。争夺不因射击相邻单位发生，只因敌方进入据点或显式占领改变。
每位玩家 holdStreak 初始0。任一成功行动及其淘汰清理完成后，若该玩家有效控制数<2，立即归零；同轮重新夺回也不恢复旧计数。每轮开始（包含第1轮，初始均0），在任何收入/招募前，对仍有效控制>=2的存活玩家 streak+=1，其余设0；达到3立即胜利。不要求连续控制同一对据点，只要求控制总数从未跌到2以下。
实例：第1轮取得2点，第2/3/4轮开始保持，分别计1/2/3，在第4轮首个玩家收入前获胜。第3轮中途失去一处归零，即使本轮夺回，第4轮开始只计1。敌人离开争夺点后原owner无收入/控制计数，须步兵重新占领。

## 淘汰、胜负与优先级（G06）

基地HP降至0或主动投降立即淘汰，清空其全部单位、资源设0、基地HP0；其拥有据点全部置中立并取消争夺，其他owner的争夺状态不变。淘汰玩家不再行动/收入/参与排名，其连接可只读观战。投降不是让其他玩家退出房间。
每次成功动作原子完成：验证 → 动作与伤害/反击 → 死亡/淘汰清理 → 据点状态与控制计数归零 → 检查存活人数 → 如结束回合则推进回合/轮。剩1人立即 ELIMINATION 获胜，不要求两个基地由同一人摧毁。主动投降被串行处理，也适用最后存活者规则。
若投降者就是当前玩家且尚未终局，视为其回合立即结束，跳至本轮下一存活玩家（或按轮末流程进入下一轮），仅新回合结算新玩家收入；非当前玩家投降不推进当前回合。暂停期间投降引发的下一回合初始化只执行一次，房间若仍有人缺席则继续暂停该已初始化回合。
第25轮最后一个存活玩家结束回合时，先检查淘汰胜利，再按有效据点数、基地HP、存活单位HP总和三个降序键比较，只比较存活玩家。顶位并列者全部列入 winners，reason=ROUND_LIMIT，draw=true；其他玩家不属于平局胜者。禁止用资源或座位打破平局。不进入第26轮，也不在第25轮末额外采样连续控制。
其他轮末进入下一轮：过滤顺序、采样控制胜利、若未结束才开始首位玩家回合并收入。已结束游戏拒绝全部玩法命令 GAME_FINISHED。胜负判定触发点内不会继续发收入或其他行动。
实例：A摧毁B、C摧毁A，C获胜；A/B据点同为1、基地同为6、单位HP分别8/7则第25轮末A胜；三个键A/B全同则A/B平局；淘汰C即使旧数据曾拥有2点也不参加排名。
